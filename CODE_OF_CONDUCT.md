# Community conduct

These guidelines apply to NetReact issues, discussions, code reviews, and other project spaces.

- Welcome questions and explain technical feedback with examples.
- Critique the proposed change. Treat contributors with respect regardless of experience, background, or identity.
- Harassment, threats, discriminatory abuse, and sharing another person's private information are unacceptable.

Report a concern privately to a repository maintainer. Include a link or description and the outcome you are seeking. Maintainers may remove harmful content, limit participation, or escalate abuse to GitHub. If a report concerns the maintainer, use GitHub's abuse-reporting tools directly. [Reporting abuse on GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
