# Reporting a security issue

For a suspected vulnerability, open the repository's Security tab. If **Report a vulnerability** is available, use that private form. In this private repository, collaborators can also contact the owner through the private channel used to coordinate their access. If neither route is available, ask the maintainer for a private contact and omit sensitive details from that request.

Include the NetReact version, operating system, affected command, observed impact, and a minimal example using dummy data. Redact credentials, private URLs, and personal directory names.

A NetReact configuration intentionally launches local programs with the current user's permissions. Review commands and readiness URLs before starting a configuration received from someone else.
